# Issue tracker: GitHub

Issues und Spezifikationen liegen in GitHub Issues für dieses Repository.
Verwende `gh` aus dem Repository-Checkout. Externe Pull Requests gehören nicht zur Issue-Triage.

- Eine Spezifikation als GitHub Issue mit Titel und vollständigem Body veröffentlichen.
- Für Spezifikationen aus `to-spec` das Label `ready-for-agent` verwenden.
- Bestehende Issues vor dem Ändern samt Kommentaren und Labels lesen.
- Issue-Nummern können auch Pull Requests bezeichnen; den Typ vor Änderungen prüfen.

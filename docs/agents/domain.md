# Domain docs

Dieses Repository verwendet einen zentralen Kontext.

- Vor Arbeit an Domänenbegriffen `CONTEXT.md` lesen und dessen Begriffe verwenden.
- Relevante Entscheidungen in `docs/adr/` lesen.
- Konflikte mit einer ADR ausdrücklich benennen.
- Fehlende Begriffe oder Entscheidungen bei Bedarf durch Domain Modeling ergänzen.
